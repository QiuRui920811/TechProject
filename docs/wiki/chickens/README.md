# 🐔 基因雞工程

基因雞工程是一套獨立的資源生產系統。透過捕捉野生雞、分析基因、選擇性繁殖，最終培育出能持續產出稀有資源的特殊品種雞。

> 此系統屬於 **農業 / 生質** 體系（AGRI_BIO），所有物品與機器歸類在科技百科的「農業 / 果園」分頁。

---

## 快速入門流程

```
製造機做雞網 → 捕捉野雞 → 基因定序器分析 DNA → 私人雞舍繁殖 → 激發室持續產出資源
```

1. 在**製造機**製作「雞網」
2. 手持雞網 **右鍵野生雞** → 獲得一隻「口袋雞」
3. 將口袋雞放入**基因定序器** → 揭示 DNA 序列
4. 挑選合適親本放入**私人雞舍** → 繁殖出帶有更多隱性基因的後代
5. 將目標品種放入**激發室** → 持續產出對應資源

## 基因系統

每隻雞擁有 **6 個基因位點**（B、C、D、F、S、W），每個位點由兩個等位基因組成：

| 符號 | 含義 | 範例 |
|---|---|---|
| 大寫 (如 B) | 顯性 | BB = 同型顯性 |
| 小寫 (如 b) | 隱性 | bb = 同型隱性 |
| 大小混合 | 異型合子 | Bb = 攜帶隱性 |

DNA 以 12 字元顯示，例如 `[Bb] [CC] [Dd] [FF] [SS] [Ww]`。

簡碼型用 3 種字母表示每個位點的狀態：
- **D** = 同型顯性（兩個都是大寫）
- **H** = 異型合子（一大一小，攜帶隱性但不表現）
- **r** = 同型隱性（兩個都是小寫）✅ 目標

### 核心規則

- **同型隱性 (r) 的位點數量 = 資源等級**（0 ～ 6 級）
- 隱性位點越多 → 資源越稀有，激發室的產出間隔也越長（越珍貴）
- 繁殖採用**孟德爾遺傳（龐氏方格）**：後代每個位點從父母各隨機取一個等位基因

### 野生雞基因分布

用雞網捕到的野生雞，每個位點會隨機分配：

| 機率 | 結果 |
|---|---|
| 約 80% | 同型顯性（AA） |
| 約 15% | 異型合子（Aa，暗藏隱性） |
| 約 5% | 同型隱性（aa） |

所以野生雞大多為顯性，少數位點會偷偷帶有隱性等位基因，需要捕捉大量並定序才能挑到好底子。

### 繁殖技巧

- 透過定序器確認誰帶有隱性，再讓帶有相同位點隱性的雞配對
- 例如：父方 `[Bb]` × 母方 `[Bb]` → 有 **25%** 機率出現 `[bb]`（同型隱性）
- 耐心選育多代，逐步累積越來越多的同型隱性位點

## 📋 完整基因對照表（64 種）

**怎麼看簡碼：** 從左到右是 `B C D F S W` 六個位點。
只有 **`r`**（兩個等位基因都是隱性）算數 —— **`D`（純顯性）和 `H`（一顯一隱）都不算**。

**資源編號 = 所有 `r` 位置的值相加：**

| 位點 | B | C | D | F | S | W |
|---|---|---|---|---|---|---|
| 位元值 | **1** | **2** | **4** | **8** | **16** | **32** |

例：`DrrDDD` → C(2) + D(4) = 編號 **6** → 礫石。`DDHDDD` → 沒有 r → 編號 **0** → 羽毛（不算資源雞）。

> 所以 **「幾個 r」決定 Tier，「r 在哪幾個位置」決定具體是哪一種資源**。
> 同樣 2 個 r 有 15 種組合，就是 15 種不同資源 —— 想要特定資源就得配出特定的 r 組合。

## 物品

### 雞網

| 屬性 | 值 |
|---|---|
| 圖示 | 牽繩 |
| 取得 | 製造機（線 ×2 + 木棍 → 雞網 ×4，3 J） |
| 解鎖 | 初始即有 |

右鍵野生雞使用，一次性消耗。雞會被移除，你會獲得一隻未定序的口袋雞。

### 口袋雞

| 屬性 | 值 |
|---|---|
| 圖示 | 雞蛋（背包中以 Nexo 自訂口袋雞外觀顯示） |
| 取得 | 雞網捕捉野生雞 |
| 解鎖 | 雞網 |

被捕獲的雞會以口袋雞形式存在於背包中，帶有隱藏的 DNA。  
經過基因定序器分析後，物品的 lore 會顯示完整基因型、簡碼型、資源等級與對應資源。

**用途：**
- 基因定序器 → 顯示 DNA
- 私人雞舍 × 2 → 繁殖後代
- 激發室 → 持續產出資源

## 機器

### 基因定序器

| 屬性 | 值 |
|---|---|
| 方塊 | 切石機 |
| 耗能 | 3 J/tick |
| 進 / 出 | 口袋雞 → 口袋雞 |
| 合成 | 製造機（玻璃 + 鐵錠 + 紅石，8 J） |
| 解鎖 | 雞網 |

將未定序的口袋雞放入輸入格 → 消耗能量 → 輸出已定序的口袋雞，DNA 資訊顯示在 lore 上。

### 私人雞舍

| 屬性 | 值 |
|---|---|
| 方塊 | 堆肥桶 |
| 耗能 | 2 J/tick |
| 進 / 出 | 口袋雞 ×2 → 口袋雞 |
| 合成 | 製造機（橡木板 + 乾草捆，5 J） |
| 解鎖 | 基因定序器 |

放入 **兩隻已定序的口袋雞** → 消耗能量 → 繁殖出一隻後代口袋雞。  
父母不會被消耗，會留在輸入格中。後代的每個位點遵循孟德爾遺傳，從父母各取一個等位基因。

**繁殖限制：**
- 每次繁殖有 **180 秒冷卻**（約 20 隻／小時），冷卻期間顯示「冷卻 Xs ┃ 壽命 Y/10」
- **速度升級**模組可縮短冷卻：每個 −40 秒，最低壓到 60 秒
- 每隻親代最多繁殖 **10 次**，用完壽命後會消失（伴隨煙霧與雞叫聲）

### 激發室

| 屬性 | 值 |
|---|---|
| 方塊 | 釀造台 |
| 耗能 | 4 J/tick |
| 進 / 出 | 口袋雞 → 對應資源 |
| 合成 | 製造機（鐵錠 + 玻璃 + 電路板，10 J） |
| 解鎖 | 私人雞舍 |

放入一隻**有同型隱性位點的已定序口袋雞** → 持續消耗能量 → 不斷在輸出格產出對應資源物品。  
等級越高，激發間隔越長，資源也越珍貴。

**升級模組：**
- **速度升級**：每個模組讓激發速率 +100%（1 個 = 2 倍速、間隔減半）；同時也縮短私人雞舍的繁殖冷卻
- **堆疊升級**：每個模組讓每次產出 +1（例如 3 個堆疊升級 = 每次產出 4 個）

**純度加成：** 雞的異型合子（H）位點越少，激發間隔會再略微縮短（最多約加速 9%），所以純化的 D/r 品種產得更快。

**激發週期與壽命：**

| 等級 | 基礎激發週期 | 壽命上限 |
|------|--------|----------|
| Tier 1 | 60 秒 | 300 次 |
| Tier 2 | 120 秒 | 150 次 |
| Tier 3 | 240 秒 | 80 次 |
| Tier 4 | 360 秒 | 50 次 |
| Tier 5 | 600 秒 | 25 次 |
| Tier 6 | 1200 秒 | 12 次 |

- 運行時顯示「激發：〈資源〉 XX% ┃ 〈秒〉s/個 ┃ 壽命 Y/Z」（實際週期會被純度與速度升級縮短）
- 雞用完壽命次數後會消失，等級越高越珍貴

## 常見問答

**Q：野生雞一定是全顯性嗎？**  
A：不是。野生雞每個位點約有 15% 機率為異型合子、5% 機率為同型隱性，需要捕捉大量並定序才能找到帶有好基因的個體。

**Q：繁殖的後代一定比父母好嗎？**  
A：不一定。孟德爾遺傳是機率性的，後代可能更好也可能退化。多次繁殖、保留最佳後代是關鍵。每隻親代只能繁殖 10 次，用完就消失，所以要挑對配對。

**Q：激發室的雞會死掉嗎？**  
A：會。每隻雞有壽命上限（Tier 1 = 300 次、Tier 6 = 12 次），用完後雞會消失，需要重新培育。

**Q：怎麼加快產出？**  
A：塞入速度升級模組（每個 +100% 速率），並把品種純化到越少異型合子越好（純度加成）。堆疊升級則是每次多產出物品，不影響速度。

**Q：可以用物流系統自動取出資源嗎？**  
A：可以，激發室的輸出格支持貨物輸出節點自動抽取。
