## 大麻（cannabis）

前期就能取得的娛樂性作物，屬於**農業**分類。

### 怎麼取得

1. **打草**（草叢、蕨類）有約 **0.35%** 機率掉「**大麻種子**」（`cannabis_seeds`）
2. 種子種在**耕地**上，跟小麥一樣會長
3. 成熟後採收 → **大麻 ×2 + 種子 ×1**（種子會回本，可以一直擴種）

也可以用**作物收割機**自動採收，骨粉催熟同樣有效。

### 抽了會怎樣

手持大麻**右鍵**會消耗一個，接著 **60 秒**內：

- **頭暈想吐**（畫面扭曲）
- **走路變慢**
- **講話語無倫次** —— 聊天訊息會被打亂：吃掉某些字、拖音、插入「呃…」「欸…」「那個…」之類的贅詞
- **嘴邊一直冒煙**（營火煙 + 一般煙）

效果結束後自動恢復，煙也會停。

| 物品 | ID | 取得 |
|---|---|---|
| 大麻種子 | `cannabis_seeds` | 打草 0.35% |
| 大麻 | `cannabis` | 種植採收（一次 ×2） |
