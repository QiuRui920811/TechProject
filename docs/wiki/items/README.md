## 物品取得方式

| 方式 | 說明 |
|---|---|
| 淘金盤篩礦 | 手持淘金盤右鍵黏土/靈魂沙/礫石，前期最核心的手動產出 |
| 機器配方 | 在對應科技機器中加工合成 |
| 工作台藍圖 | 在進階工作台以 3×3 合成 |
| 星球採集 | 前往各星球世界採集專屬資源 |
| 種植/收穫 | 種下果樹苗或作物種子後收成 |
| 怪物掉落 | 星球特殊怪與迷宮守衛者掉落戰鬥樣本 |
| 附魔祭壇 | 古代祭壇與附魔基座的儀式合成 |
