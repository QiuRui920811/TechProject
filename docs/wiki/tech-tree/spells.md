# 法術系統（已移至 TechMMO）

> 📦 施法與技能系統已從科技插件（TechProject）搬到 **TechMMO** 插件。科技插件這邊不再管法術，本頁只保留導向資訊。

法術現在屬於 **TechMMO** 的技能系統，透過各職業的天賦樹解鎖，改用 `/mmo` 指令查看：

| 指令 | 用途 |
|---|---|
| `/mmo skills` | 開技能 / 職業總覽介面，查看已解鎖的技能 |
| `/mmo tree [職業]` | 開天賦樹介面，在基石節點解鎖法術 |
| `/mmo` | 開自己的角色面板 |
| `/mmo help` | 列出完整指令 |
