# 科技樹（科技解鎖進程）

這裡的「科技樹」指的是**研究解鎖進程**，從研究台起步，一路沿著解鎖鏈邁向宇宙巔峰。累積研究經驗值，就能逐階打開越來越高端的機器與材料。


---

## 職業、天賦、技能、法術

這些不在科技樹裡，走另一套系統，用 `/mmo` 指令：

| 指令 | 用途 |
|---|---|
| `/mmo` | 開自己的角色面板 |
| `/mmo class` | 選擇或切換職業 |
| `/mmo tree [職業]` | 開天賦樹，分配天賦點 |
| `/mmo skills` | 查看已解鎖的技能 |
| `/mmo help` | 完整指令列表 |

目前有 5 種職業：劍士、射手、坦克、法師、刺客，各有一棵天賦樹。法術在天賦樹的基石節點解鎖。


> 兩套系統各走各的指令：RPG 職業／天賦用 `/mmo`，科技研究解鎖用 `/tech`。

## 一階 — 工業基礎

**解鎖成本**: 物品 14 經驗 / 機器 30 經驗

初始免費解鎖的機器：碎礦機、自動農場、電鋸、回收機、太陽能發電機、燃煤發電機

### 核心產線

```
鐵礦 ──[碎礦機]──→ 鐵粉 ──[電爐]──→ 鐵錠 ──[壓縮機]──→ 鐵板
 ↓
銅礦 ──[碎礦機]──→ 銅粉 ──[電爐]──→ 銅錠 ──[製造機]──→ 電路板
 ↓
石英 ──[碎礦機]──→ 矽 ───────────────────[製造機]──→ 機械零件
 ↓
原木 ──[電鋸] ──→ 木屑精密框架
```

## 二階 — 中期擴展

**解鎖成本**: 物品 32 經驗 / 機器 64 經驗

### 精煉鏈

```
鐵粉 ──[洗礦機]──→ 礦漿 ──[淨化器]──→ 淨化碎晶 ──[離心機]──→ 離子粉
```

### 生質鏈

```
作物+木屑 ──[生質實驗室]──→ 生質樹脂 ──[化學反應器]──→ 聚合樹脂
 ↓
 ──[聚合壓床]──→ 橡膠片
```

## 三階 — 高階科技

**解鎖成本**: 物品 72 經驗 / 機器 128 經驗

```

 ↓
紫水晶+冷卻液 ──[晶體培育艙]──→ 晶種 → 培育晶體
 ↓
 ──[力場鍛造台]──→ 力場板
 ↓
 ──[聚變反應爐]──→ 聚變核心
 ↓
 ──[物質編譯器]──→ 奇點碎片
```

## 四階 — 終局

**解鎖成本**: 物品 132 經驗 / 機器 208 經驗

13 台機器形成嚴格的線性鏈條，從虛空抽取器開始，到歐米茄製造器結束。

詳見 [四階機器](../machines/tier-4.md) 和 [終局材料](../items/endgame-materials.md)。

## 平行路線

### 擴展科技線 (二～三階)

```
窯爐 → 絕緣壓機 → 低溫蒸餾器 (熱/絕緣/低溫)
基因剪接台 → 生質合成槽 (生物合成)
電漿精煉器 → 光子編織機 (電漿/光子)
天文觀測台 → 測繪信標 → 遺物解析儀 (天文/行星)
異星精煉槽 → 行星鍛造台 (行星裝備)
```

### 行星路線 (三階)

```
天文觀測台 → 測繪信標 → 星門 → 行星探索
 ↓
 遺物解析儀 → 異星精煉槽 → 行星鍛造台
 ↓ ↓
 古代訊號異星合金 → 防護套裝
```

### 系統自動化路線 (二～三階)

```
礦場鑽機 Mk1/Mk2/Mk3 (自動採礦)
作物收割機 / 伐木機 / 釣魚碼頭 (資源收集)
倉儲匯流站 / 過濾路由器 / 貨物系統 (物流管理)
安卓機器人 (全自動化)
```
