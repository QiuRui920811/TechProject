# 天賦樹系統（已移至 TechMMO）

> 📦 這套系統已從科技插件（TechProject）搬到 **TechMMO** 插件。科技插件這邊不再管職業與天賦，本頁只保留導向資訊。

職業、天賦樹、屬性點現在全部由 **TechMMO** 管理，改用 `/mmo` 指令操作：

| 指令 | 用途 |
|---|---|
| `/mmo tree [職業]` | 開天賦樹介面，查看與分配天賦點（不加參數＝職業選擇器） |
| `/mmo skills` | 開技能 / 職業等級總覽介面 |
| `/mmo class` | 開職業選擇器，選擇或切換職業 |
| `/mmo` | 開自己的角色面板 |
| `/mmo points talent add <數量> [玩家]` | （管理員）發放天賦點 |
| `/mmo help` | 列出完整指令 |

目前開放 5 種職業，各有一棵天賦樹：劍士、射手、坦克、法師、刺客。天賦點在 `/mmo tree` 的天賦樹介面裡分配。
