# 成就系統

完成特定目標獲得研究經驗、能源代幣和專屬稱號。共 **74** 項成就，每項解鎖後都會授予一枚對應的專屬稱號。

---

## 成就獎勵

- **研究經驗**：加速解鎖科技樹
- **能源代幣**：特殊貨幣
- **稱號**：專屬頭銜（可透過 `/tech title` 查看和裝備）

## 稱號系統

每個成就解鎖後都會獲得對應的專屬稱號。稱號以全形括號 `〔〕` 包裹，帶有分類色彩。

### 稱號指令

| 指令 | 說明 |
|---|---|
| `/tech title` | 查看已解鎖的稱號 |
| `/tech title clear` | 取消目前稱號 |
