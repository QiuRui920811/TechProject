# 系統機器

大型自動化設備，用於大規模資源採集和管理。與工作台機器不同，系統機器多半以「範圍」或「區塊」為單位運作，放好後只要供電就會自己跑。

---

## 採礦系統

### 採礦鑽機

區塊級向下抽取礦脈的自動化平台，共三個型號，功率與速度逐級提升。

| 型號 | id | 階級 | 耗能 | 說明 |
|---|---|---|---|---|
| 採礦鑽機 | `quarry_drill` | 三階 | 24 EU/刻 | 區塊級向下抽取礦脈 |
| 採礦鑽機二型 | `quarry_drill_mk2` | 三階 | 48 EU/刻 | 區塊級高速抽取礦脈 |
| 採礦鑽機三型 | `quarry_drill_mk3` | 四階 | 96 EU/刻 | 區塊級終局抽礦平台 |

#### 製造路線

| 產物 | 材料 | 機器 |
|---|---|---|
| 採礦鑽機 | 鑽頭組 + 採礦機架 | 製造機 |
| 採礦鑽機二型 | 採礦鑽機 + 電容組 + 控制單元 | — |
| 採礦鑽機三型 | 採礦鑽機二型 + 聚變核心 + 量子框架 | — |

> 採礦機架（`quarry_frame`）由製造機以機械零件合成，是所有鑽機的共用前置骨架。

#### 注意事項

- 黑名單方塊無法挖掘：基岩、屏障、指令方塊等
- 挖到的礦石依方塊種類自動轉為對應掉落物（鑽石礦→鑽石、綠寶石礦→綠寶石、古代碎片→古代碎片等）
- 需要持續供電，斷電即停止

| 屬性 | 值 |

#### 支援生物

| 類別 | 生物 |
|---|---|
| 被動 | 牛、羊、豬、雞、兔子 |
| 常見怪物 | 僵屍、骷髏、苦力怕、蜘蛛、史萊姆、屍殼、流浪者、溺屍 |
| 地獄生物 | 烈焰人、岩漿怪、惡魂、凋靈骷髏、僵屍豬布林、豬布林、豬布林蠻兵、豬布獸、豬屍獸、熾足獸 |
| 生電常用 | 鐵傀儡、女巫、末影人 |
| 突襲生物 | 掠奪者、衛道士、喚魔者、劫毀獸 |
| 海底生物 | 守衛者、遠古守衛者 |

> 對應掉落物涵蓋皮革、生牛肉、白羊毛、生羊肉、生豬肉、雞肉、羽毛、腐肉、骨頭、火藥、線、蜘蛛眼、史萊姆球、烈焰棒、岩漿膏、惡魂之淚、煤炭、金粒等。

#### 生物黑名單

以下生物不受影響：玩家、盔甲架、村民、流浪商人、命名生物、馴服生物、拴繩生物、幼年生物等。

## 地質系統

在挖礦之外，地質系統讓你先勘探、再定點抽取深層資源。

### 地質掃描器

| 屬性 | 值 |
|---|---|
| id | `geo_scanner` |
| 階級 | 三階 |
| 耗能 | 12 EU/刻 |
| 功能 | 利用探針與定位標記掃描區塊地質資料 |
| 進 / 出 | 地質掃描探針、定位標記 → 數據矩陣 |

### 地質抽取機

| 屬性 | 值 |
|---|---|
| id | `geo_extractor` |
| 階級 | 三階 |
| 耗能 | 18 EU/刻 |
| 功能 | 持續抽取腳下區塊的地質資源，需先用地質掃描器勘探 |
| 進 / 出 | 鑽頭組、精密框架 → 原油、岩鹽、硫磺粉、鈾原礦、銅粉 |
