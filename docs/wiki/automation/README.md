## 自動化等級

### 等級一：基礎自動化

```
自動農場 → 作物自動種植收穫
太陽能發電機 → 自動發電
```

### 等級 1.5：純電力版機器

```
手動機器 + 自動化模組 → 純電力版
 ├── 電動粉碎機 → 全自動粉碎
 ├── 電動壓縮機 → 全自動壓縮
 ├── 電動洗礦機 → 全自動洗礦
 ├── 電動拉線機 → 全自動拉線
 ├── 電動淨化器 → 全自動淨化
 ├── 電動離心機 → 全自動離心
 ├── 電動生質實驗室 → 全自動生質培養
 └── 電動化學反應器 → 全自動化學合成
```

> 耗能約手動版 2×，但完全不需手動右鍵觸發。詳見 [純電力版機器](../machines/electric-machines.md)

### 等級二：系統自動化

```
採礦鑽機 → 區塊級自動挖礦（三型號 24 / 48 / 96 EU/秒）
作物收割機 → 大範圍收割並自動重植
伐木機 → 整株砍伐附近樹木
自動釣台 → 依水域持續取得漁獲
真空吸入口 → 吸入周圍掉落物
生物收集器 → 收集怪物掉落物
風暴渦輪機 / 風力渦輪機 → 天氣 / 風力發電
地質掃描儀 + 地質抽取機 → 勘探並抽取深層地質資源
```

### 等級三：完全自動化

```
安卓機器人 → AI 工人（插入不同程序腳本執行任務）
 ├── 農務程序 → 自動種植/收穫
 ├── 伐木程序 → 自動伐木
 ├── 回收程序 → 自動回收
 ├── 行星採樣程序 → 行星資源採集
 ├── 探索程序 → 任何世界探勘稀有礦物
 ├── 獵捕程序 → 獵捕生物收集掉落物
 └── 自訂程序 → 玩家編寫 DSL 巡邏邏輯
```
