# 克里昂

極寒冰封的外星球，永恆暴風雪覆蓋的冰原世界。

## 獨有資源

| 資源 | id | 說明 |
|---|---|---|
| 霜核晶簇 | `cryonite_crystal` | 冰層採集，寒域研究的基礎地質樣本，精煉低溫內襯、可做霜芯暖鍋 |
| 霜綻花 / 霜綻花種子 | `frostbloom` / `frostbloom_seeds` | 能在極寒下保有活性的寒性植株，種子可帶回農地培育 |

## 遺跡探索

1. 探索星球找到遺跡（磁石結構）
2. 手持**測繪資料**右鍵點擊磁石
3. 進入 3 波戰鬥挑戰，清完獲得**霜境遺物**（後續解析成古訊號片段）

---

## 低溫防護

### 低溫套裝

在行星鍛造台中合成，四件套的部件 id 為 `thermal_helmet` / `thermal_chestplate` / `thermal_leggings` / `thermal_boots`（遊戲內顯示為「抗寒」系列）：

| 部件 | 材料 |
|---|---|
| 頭盔 | 外骨骼框架 + 氣密織層 + 低溫內襯 |
| 胸甲 | 外骨骼框架 + 氣密織層 + 低溫內襯 |
| 護腿 | 外骨骼框架 + 氣密織層 + 低溫內襯 |
| 戰靴 | 外骨骼框架 + 氣密織層 + 低溫內襯 |

**低溫內襯** (`thermal_lining`)：由**異星精煉槽**用【古訊號片段 + 霜核晶簇 + 冰脈核心】精煉而成。

### 反食物

**霜芯暖鍋** (`cryon_hotpot`) — 霜蘋果 + 低溫晶體

## 星球怪物

### 怪物強化

克里昂的一般怪物會被強化：

| 屬性 | 強化值 |
|---|---|
| 生命值 | × 1.35 |
| 攻擊力 | + 1.5 |
| 移動速度 | 略微提升 |

### 怪物技能

一般怪物攻擊玩家時有 **30%** 機率觸發技能（冷卻 6 秒）：
- **極寒凍結**：施加緩速效果 + 凍結玩家

### 霜脊潛獵者（菁英）

| 屬性 | 值 |
|---|---|
| 血量倍率 | × 2.4 |
| 攻擊加成 | + 2.5 |
| 移動速度 | + 0.02 |

- 掉落 **冰脈核心** (`cryon_ice_heart`)
- 額外掉落 **霜核晶簇** (`cryonite_crystal`)

---

## 探索建議

- 穿著低溫套裝防止凍傷
- 攜帶霜芯暖鍋應對突發狀況
- 收集霜核晶簇和霜綻花種子，霜蘋幼株也可帶回基地培育
- 擊敗冰原菁英取得冰脈核心
