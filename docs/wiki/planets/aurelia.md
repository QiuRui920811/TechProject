## 遺跡探索

1. 探索星球找到遺跡（重生錨結構）
2. 手持**測繪資料**右鍵點擊重生錨
3. 進入 3 波戰鬥挑戰，清完獲得**星核遺物**（後續解析成古訊號片段）

## 輻射防護

### 抗輻射套裝

在行星鍛造台中合成，四件套的部件 id 為 `anti_radiation_helmet` / `anti_radiation_chestplate` / `anti_radiation_leggings` / `anti_radiation_boots`：

| 部件 | 材料 |
|---|---|
| 頭盔 | 外骨骼框架 + 氣密織層 + 輻射網層 |
| 胸甲 | 外骨骼框架 + 氣密織層 + 輻射網層 |
| 護腿 | 外骨骼框架 + 氣密織層 + 輻射網層 |
| 戰靴 | 外骨骼框架 + 氣密織層 + 輻射網層 |

**輻射網層** (`radiation_mesh`)：由**異星精煉槽**用【古訊號片段 + 輻照碎晶 + 輻塵腺體】精煉而成。

### 反食物

**輻晶蜜凍** (`aurelia_glaze`) — 流明果 + 輻照碎片

| 屬性 | 強化值 |

## 探索建議

- 首次登陸前在生質實驗室合成「**輻射濾除劑**」(`rad_filter_pill`，生質觸媒 + 神經樹脂)，提供短暫輻射防護
- 多帶幾顆輻射濾除劑，到星球後採集輻照碎晶並擊殺菁英取得輻塵腺體
- 回地球後做出完整抗輻射套裝，再二次登陸深入探索
- 收集虛域花簇種子與流明果苗帶回地球種植（農地即可種下）
