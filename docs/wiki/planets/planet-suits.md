# 行星防護套裝

為外星球探索設計的四套專用防護裝備，全部在**行星鍛造台**（`planetary_forge`）組裝。

---

| 套裝 | 防護 | 適用星球 | 部件 id 前綴 |
|---|---|---|---|
| 抗輻射套裝 | ☢️ 輻射 | 奧蕾莉亞 | `anti_radiation_*` |
| 低溫套裝 | ❄️ 低溫 | 克里昂 | `thermal_*`（顯示「抗寒」）|

> ⚠️ 注意：**低溫套裝的部件顯示為「抗寒頭盔／胸甲／護腿／靴」**、**真空套裝顯示為「抗壓」系列**，套裝名與部件名不同，別跟前期的鉛合金 `hazmat_*`（防輻射套裝）搞混。

## 生產鏈

防護裝的核心是兩台機器：

```
古訊號片段 + 星球地表樣本 + 星球戰鬥樣本
        ↓  異星精煉槽 (xeno_refinery)
異星合金 + 各防護模組（輻射網層 / 低溫內襯 / 壓差膜層 / 日灼屏蔽層 / 風暴偏轉層）
        ↓  行星鍛造台 (planetary_forge)
外骨骼框架 + 氣密織層 + 防護模組  →  套裝部件
```

- **異星精煉槽**：把古訊號片段、地表樣本、戰鬥樣本精煉成**異星合金**與各**防護模組**
- **行星鍛造台**：用異星合金、氣密織層、外骨骼框架與防護模組組裝出各套裝部件

## 前線套裝

**對抗**：所有六種環境危害（含赫利昂日灼、坦佩斯特風暴、迷途星瘴氣）。前線套裝是最終極的防護裝備，可以在任何星球自由活動。

### 前線核心

合成前線套裝的核心材料：

```
前線核心碎片 (frontier_core_fragment，赫利昂 / 坦佩斯特高階遺跡)
    + 異星合金 (xeno_alloy)
    + 灰燼燃核 (helion_cinder_core，赫利昂菁英)
    + 風暴電容核 (tempest_capacitor，坦佩斯特菁英)
    ↓  行星鍛造台
前線防護核心 (frontier_core)
```

### 部件

## 合成路線建議

```
初階三星球探索（測繪資料啟動）→ 星球遺物 + 戰鬥樣本
    ↓
遺物解析儀 → 古訊號片段 → 異星精煉槽 → 異星合金 + 防護模組
    ↓
行星鍛造台 → 初階套裝（一次做一套）
    ↓
進階星球（赫利昂 + 坦佩斯特）→ 灰燼燃核 + 風暴電容核 + 前線核心碎片
    ↓
前線核心 → 前線套裝（最終目標）
```
