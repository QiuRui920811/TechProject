## 遺跡探索

1. 探索星球找到遺跡（末地傳送門框架結構）
2. 手持**測繪資料**右鍵點擊末地傳送門框架
3. 進入 3 波戰鬥挑戰，清完獲得**倪克斯遺核**（後續解析成古訊號片段）

> 💡 挑戰波已做地面化調整，移除 PHANTOM（改為 ENDERMAN / SKELETON / CREEPER），避免飛行單位越界卡住玩家。

## 真空防護

### 真空套裝

在行星鍛造台中合成，四件套的部件 id 為 `pressure_helmet` / `pressure_chestplate` / `pressure_leggings` / `pressure_boots`（遊戲內顯示為「抗壓」系列）：

| 部件 | 材料 |
|---|---|
| 頭盔 | 外骨骼框架 + 氣密織層 + 壓差膜層 |
| 胸甲 | 外骨骼框架 + 氣密織層 + 壓差膜層 |
| 護腿 | 外骨骼框架 + 氣密織層 + 壓差膜層 |
| 戰靴 | 外骨骼框架 + 氣密織層 + 壓差膜層 |

**壓差膜層** (`pressure_membrane`)：由**異星精煉槽**用【古訊號片段 + 虛璃碎片 + 相位膜組織】精煉而成。

### 反食物

**相位凝露** (`nyx_phase_gel`) — 影莓 + 虛玻碎片

## 探索建議

- 倪克斯使用末地維度，地形更加危險
- 注意虛空墜落風險
- 穿著真空套裝防止窒息
- 攜帶相位凝露應對緊急狀況
- 收集虛璃碎片是合成高階壓差材料的關鍵，回響孢子囊可帶回種植
