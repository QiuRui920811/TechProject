# 星門建造

行星星門是連接地球與外星球的傳送裝置。

---

## 星門屬性

| 屬性 | 值 |
|---|---|
| 機器名稱 | 行星星門 (`planetary_gate`) |
| 階級 | 三階|
| 待機吸能 | **12 EU/tick**（維持星門開啟）|
| 躍遷能耗 | **額外 1200 EU**（每次傳送）|

---

## 星門建造

### 所需材料

行星星門的組裝材料（依機器配方）：

| 材料 | 來源 |
|---|---|
| 行星測繪資料 `survey_data` | 行星測繪信標 |
| 重力軸承 `gravitic_bearing` | 軌道觀測台 |
| 量子框架 `quantum_frame` | 量子處理器 |
| 資料核心 `data_core` | 軌道觀測台 |

最終合成：**行星測繪資料 + 重力軸承 + 量子框架 + 資料核心** → 行星星門

### 前置科技鏈

```
軌道觀測台 → 星圖 → 星圖測繪晶片
     ↓
行星測繪信標 → 行星測繪資料
     ↓
探索初階星球 → 星球遺物 → 遺物解析儀 → 古訊號片段
                                          ↓
                                   異星精煉槽 → 異星合金
                                          ↓
                               進階製造機 → 行星星門
```

---

## 星門使用

### 步驟

1. 放置星門方塊
2. 確保能源網路能供應**待機 12 EU/tick** 並在躍遷時再吃下 **1200 EU**
3. 右鍵點擊星門開啟選單
4. 選擇目的地星球
5. 確認傳送

### 星門選單

| 位置 | 目的地 |
|---|---|
| 🌍 | 地球 (返回) |
| ☢️ | 奧蕾莉亞 |
| ❄️ | 克里昂 |
| 🌑 | 倪克斯 |
| ☀️ | 赫利昂 |
| ⚡ | 坦佩斯特 |
| 🌫️ | 迷途星 |

## 能源需求

星門是最耗能的設施之一：

- 待機維持 **12 EU/tick**（即使沒在傳送也會持續吸能）
- 每次躍遷傳送**額外消耗 1200 EU**
- 建議搭配太陽能陣列或聚變反應爐供電
- 可使用電池庫儲存能量，應付躍遷瞬間的大電流

### 推薦供電方案

```
聚變反應爐 → 能源節點 → 電池庫 → 星門
               或
太陽能陣列 (多台) → 能源節點 → 電池庫 → 星門
```

---

## 注意事項

- 傳送後會出現在星球的隨機位置
- 行星邊界半徑 3000 方塊，超出會被傳回
- 確保穿著對應防護套裝再傳送
- 可在星球建立多個星門方便返回
