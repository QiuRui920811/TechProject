# 農務種植

TechMC 新增了科技作物、外星果實和一般水果系統。

---

## 科技作物

透過自動農場或溫室培育艙解鎖種子後種植：

| 種子 | 產出 | 取得方式 |
|---|---|---|
| 大豆種子 | 大豆莢 | 自動農場 (作物種子 + 肥料混合物) |
| 番茄種子 | 熟番茄 | 自動農場 (作物種子 + 生質觸媒) |
| 高麗菜種子 | 高麗菜球 | 自動農場 (作物種子 + 水凝膠) |
| 玉米粒種 | 甜玉米 | 溫室 (種子簇 + 生質觸媒) |
| 洋蔥球根 | 洋蔥 | 溫室 (種子簇 + 基因樣板) |
| 香辛莓種子 | 香辛莓 | 溫室 (種子簇 + 肥料混合物) |
| 茶葉苗種 | 科技茶葉 | 溫室 (種子簇 + 水凝膠) |

> 作物種子、種子簇、肥料混合物皆為自動農場產物；水凝膠由溫室（生質樹脂 + 作物）製作。

## 種植系統

### 自動農場
- 一階機器
- 放入種子和骨粉自動種植
- 產出基礎作物、大豆、番茄、高麗菜

### 溫室培育艙
- 二階機器
- 解鎖特殊種子、樹苗與灌木
- 需要生長燈和農業模組

### 星球種植
- 三階進階
- 在對應星球種植外星果實
- 需要行星防護套裝
- 虛域花簇等生質植株的種子可帶回地球在普通農地種植
