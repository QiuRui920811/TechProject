# 機器食品

透過科技機器合成的進階食品，通常比互動烹飪提供更高的飽食度。

---

## 生質實驗室料理

一階生質實驗室（升級為電動版後更快）可把作物合成料理：

| 食物 | 材料 |
|---|---|
| 果園沙拉 | 熟番茄 + 高麗菜球 |
| 柑橘沙拉 | 香橙 + 黃檸果 |
| 番茄燉鍋 | 熟番茄 + 洋蔥 |
| 捲心菜捲 | 高麗菜球 + 洋蔥 |
| 玉米麵包 | 甜玉米 + 大豆莢 |
| 拉麵 | 大豆莢 + 甜玉米 |
| 壽司捲 | 甜玉米 + 熟番茄 |
| 起司披薩 | 熟番茄 + 大蒜 |
| 蔬菜捲餅 | 生菜 + 熟番茄 |
| 早安捲餅 | 甜椒 + 甜玉米 |
| 蔬菜咖哩 | 洋蔥 + 甜椒 |
| 水果帕菲 | 草莓 + 藍莓 |
| 科技營養棒 | 大豆莢 + 香辛莓 |
| 異星果泥 | 流明果 + 幽影莓串 |

> 生質實驗室另可製作**曙光茶飲**（雷莓李 + 水凝膠，亦可用茶葉），詳見 [飲料](drinks.md)；並可製作星球反食物**輻晶蜜凍**與**輻射濾除劑**（見下方）。
> **異星果泥**是後續蛋糕、口糧與冰品的重要基底。

---

## 生質合成槽料理

需先解鎖基因剪接台和生質合成槽。此類配方多為「主料 ×2 + 副料」：

| 食物 | 材料 |
|---|---|
| 合成肉塊 | 基因樣板 ×2 + 生質觸媒 |
| 蛋白口糧包 | 合成肉塊 ×2 + 大豆莢 |
| 果園後勤口糧 | 異星果泥 ×2 + 大豆莢 |
| 科技營養棒 | 曜焰無花果 ×2 + 異星果泥 |
| 晨光果派 | 香橙 ×2 + 蜜桃 |
| 蜜桃派盆 | 蜜桃 ×2 + 甜玉米 |
| 青梨脆派 | 青梨 ×2 + 玉米麵包 |
| 漿果塔派 | 幽影莓串 ×2 + 香辛莓 |
| 起司蛋糕 | 異星果泥 ×2 + 生質觸媒 |
| 巧克力蛋糕 | 異星果泥 ×2 + 香辛莓 |

> **蛋白口糧包**、**果園後勤口糧**是長時間戶外作業與高壓探索的耐久口糧，提供飽食、抗性與工作效率。
> 生質合成槽也可製作星球反食物**霜芯暖鍋**（見下方）。

## 星球反食物

特殊食物可以減輕對應星球環境的負面效果：

| 反食物 | 星球 | 材料 | 製造機器 | 持續 |
|---|---|---|---|---|
| **輻射濾除劑** | 奧蕾莉亞 | 生質觸媒 + 神經樹脂 | 生質實驗室 | 90 秒 |
| 輻晶蜜凍 | 奧蕾莉亞 | 流明果 + 輻照碎晶 | 生質實驗室 | 180 秒 |
| 霜芯暖鍋 | 克里昂 | 霜蘋果 ×2 + 霜核晶簇 | 生質合成槽 | 180 秒 |
| 相位凝露 | 倪克斯 | 幽影莓串 + 虛璃碎片 | 冷卻混合器 | 180 秒 |
| 日冕雪酪 | 赫利昂 | 曜焰無花果 ×2 + 日耀碎晶 | 低溫蒸餾器 | 180 秒 |
| 雷雲汽泡飲 | 坦佩斯特 | 雷莓李 + 風暴玻片 | 冷卻混合器 | 180 秒 |

> 💡 **提示**：**輻射濾除劑**的材料全部可在地球取得，是首次登陸奧蕾莉亞的最佳選擇。其他星球反食物需要在對應星球採集材料（外星果實與地質碎晶）。
