# 巨構機器

巨構機器是 四階之上的超終局內容，生產最終級材料，一路指向整條科技樹的封頂產物 **終極檔案庫**。

全部 8 台巨構機台都屬於 `TIER4` 四階，耗能極高（30～52 EU/tick），需要先把前置終局機台（星核熔鍛爐、虛空信標、時序引擎……）跑起來才能解鎖。

---

## 巨構解鎖鏈

```
星核熔鍛爐   → 星鋼鑄造廠
虛空信標     → 真空工藝艙
虛空信標     → 錨定鍛造台
時序引擎     → 曲率裝配機
奇點壓縮台   → 事件視界鍛台
熵穩定艙     → 連續體車床
資料封存庫   → 遺產掃描儀
終極製核儀   → 巔峰鍛成儀 → 終極檔案庫
```

> 每一台的「解鎖」欄位就是它的前置機台，做出前置機台後才會在指南裡亮出對應的巨構機器。

## 巔峰鍛成儀

整條巨構鏈的終點機台，把宇宙矩陣、封存核心、連續體外殼與遺產資料層層壓縮，最後鍛成 **終極檔案庫**。

| 屬性 | 值 |
|---|---|
| 內部 ID | `apex_forge` |
| 方塊 | 附魔台 |
| 耗能 | 52 EU/tick |
| 解鎖 | 終極製核儀 |

| 輸入 | 輸出 | 能源 |
|---|---|---|
| 宇宙矩陣 ×2 + 封存核心 ×2 | 終極矩陣 | 50 EU |
| 終極矩陣 ×2 + 連續體外殼 ×2 | 巔峰核心 | 52 EU |
| 巔峰核心 ×2 + 遺產資料 ×3 | 終極檔案庫 | 54 EU |

> 🌟 **終極檔案庫**（`omega_archive`）是整條科技線的最終產物——它不是一台機器，而是巔峰鍛成儀鍛出的封頂物品。持有它代表你已征服所有科技內容！

## 巨構產線總覽

```
星核熔鍛爐 → 星核合金 / 星輝玻璃
    ↓
星鋼鑄造廠 → 星鋼錠 → 星鋼框架
真空工藝艙 → 真空玻璃 / 諧振晶體 / 天穹透鏡 / 星雲纖維
曲率裝配機 → 曲率電池 → 曲率線圈 / 星界電路
事件視界鍛台 → 事件視界板 / 奇點外殼
連續體車床 → 時序格架 → 連續體外殼 / 極光板
遺產掃描儀 → 遺產資料 / 封存核心
錨定鍛造台 → 維度錨 → 叢集匯流核心
                      ↓
        巔峰鍛成儀 → 終極矩陣 → 巔峰核心 → 終極檔案庫 🏆
```

> 🏆 **終極檔案庫** 是 Game Completion 的象徵，把它鍛出來代表玩家已經跑完整個科技樹。
