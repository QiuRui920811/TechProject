# 工業擴展機器

工業擴展新增了 20 台專業機器，涵蓋基礎加工、多方塊結構、發電與冷卻四大類。這些機器構成了從基礎金屬到核能的完整工業鏈。

---

| 階段 | 機器數量 | 說明 |
|---|---|---|
| [基礎工業](#基礎工業) | 7 | 焦爐、合金、洗礦、離心、壓縮、電解、電爐 |
| [多方塊結構](#多方塊結構) | 4 | 高爐、工業冶煉爐、加壓室、鑄造台 |
| [發電機組](#發電機組) | 4 | 蒸汽、柴油、燃氣渦輪、地熱 |
| [冷卻系統](#冷卻系統) | 4 | 散熱片、水冷、冷卻液循環、低溫塔 |
| [核反應堆](#核反應堆) | 1 | 鈾燃料棒 + 永久催化冷卻液發電 |

## 核反應堆

終極發電設備，使用鈾燃料棒與反應堆冷卻液產生大量電力。

| 屬性 | 值 |
|---|---|
| 內部 ID | `nuclear_reactor` |
| 方塊 | 重生錨 |
| 階級 | 三階 |
| 輸入 | 鈾燃料棒 + 反應堆冷卻液 |
| 副產物 | 乏燃料棒 |
| 解鎖 | 集齊鈾燃料棒與反應堆冷卻液 |

**運作機制**

- **反應堆冷卻液**是【永久催化劑】，放入一次後永不消耗。
- 每根**鈾燃料棒**可運轉 40 秒，穩定輸出 **200 EU/秒**（裝上加速模組額外 +60 EU）。
- 循環結束會自動輸出**乏燃料棒**，可於物質編譯器回收為新燃料棒。
- 無燃料時完全不發電。

**燃料鏈**

| 步驟 | 配方 | 機台 |
|---|---|---|
| 濃縮鈾 | 鈾礦粉 ×4 → 濃縮鈾 | 工業離心機 |
| 鈾燃料棒 | 濃縮鈾 ×2 + 鋼板 → 鈾燃料棒 | 製造機 |
| 反應堆冷卻液 | 冷卻罐 + 低溫凝膠 → 反應堆冷卻液 ×2 | 電動化學反應器 |
| 乏燃料回收 | 乏燃料棒 ×2 → 鈾燃料棒 ×1 | 電動離心機 |

> ⚠️ 反應堆閉環：冷卻液永久不消耗，只需持續回收乏燃料棒即可長期發電，「2 燒 1 回收」的差額用鈾礦補足。冷卻不足會導致停機。

## 工業加工鏈

```
原版礦石 ──[粉碎機]──→ 金屬粉 ──[工業洗礦機]──→ 錫粉 / 鉛粉 / 冷卻電池
 ↓
焦爐 ──→ 焦炭 + 雜酚油 [電爐] → 金屬錠
 ↓ ↓ ↓
 高爐(鋼) 柴油發電 [合金爐] → 合金錠
 ↓ ↓
 工業冶煉爐 → 大馬士革鋼 → 硬化合金 → 強化合金
 ↓
 熔融金屬 ──[鑄造台+模具]──→ 板/齒輪/線/棒/管

電解分離機 → 氫氣瓶/矽晶/硒粉
 ↓
 燃氣渦輪(氫氣發電)

工業離心機 → 濃縮鈾 ─[製造機]→ 鈾燃料棒 ──→ 核反應堆
 ↑
 反應堆冷卻液（永久催化劑）
```
