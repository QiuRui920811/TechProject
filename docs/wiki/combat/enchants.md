# 特殊附魔系統

TechMC 的特殊附魔是一套**獨立於原版附魔**的秘法系統 —— 走物品的 物品內建資料 儲存、不佔用原版附魔欄，因此可以疊在已有原版附魔的裝備上，同一件裝備也能同時擁有多條特殊附魔。

所有特殊附魔分 **I / II / III** 三階，透過**附魔祭壇（法陣）儀式**賦予，成功帶有機率。

## 附魔祭壇（法陣）

特殊附魔透過**附魔祭壇**的儀式賦予。祭壇由 **1 個核心 + 6 個基座**組成六角法陣。

### 蓋法（俯視圖，全部同一高度）

```
 x=-3 -2 0 +2 +3
 z=-3 ▣ ▣ 西北(-2,-3) / 東北(+2,-3)
 z= 0 ▣ ◆核心 ▣ 正西(-3,0) / 正東(+3,0)
 z=+3 ▣ ▣ 西南(-2,+3) / 東南(+2,+3)
```

- `◆` = **遠古祭壇**（`ancient_altar`）核心
- `▣` = **遠古基座**（`ancient_pedestal`）×6，距核心約 3 格

### 用法

1. **放料上基座**：手持材料**右鍵基座**，料會浮在基座上（再右鍵可收回，破壞基座會還料）。
 - **1 個基座放附魔卷軸**（決定哪一種附魔）
 - **其餘基座放共鳴寶石**：放幾顆 = 附上幾階（1→I、2→II、3→III，最高 3）
 - ⚠️ **6 個基座都要有東西**，空一個就不會啟動。最省事：**1 卷軸 + 5 共鳴寶石 = III 階、剛好填滿**。
2. **手持要附魔的裝備**（必須跟附魔分類相符：武器附魔拿劍/斧、弓附魔拿弓/弩、防具附魔拿頭胸腿靴、工具附魔拿鎬斧鏟鋤）。
3. **右鍵核心** → 六基座射出光柱匯聚 → 擲骰：

 | 階級 | 成功率 |
 |---|---|
 | I | 90% |
 | II | 65% |
 | III | 40% |

4. 成功 → 裝備 lore 多一行 `❖ 附魔名`。**不論成敗，6 基座的祭品全部消耗**（高階是賭注）。

### 附魔卷軸

每種附魔都有對應的卷軸，卷軸 id = `scroll_` + 附魔英文 id。

- 製作：**電路板 ×2 + 共鳴寶石 + 書 → 製造機**
- 共鳴寶石本身也在製造機用共鳴儀式產出

---

> 特殊附魔走 物品內建資料 儲存，不影響原版附魔；同一件裝備可疊多條不同的特殊附魔。
