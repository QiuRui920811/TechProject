# 護甲套裝

TechMC 有 **8 套完整護甲（32 件）**：3 套科技護甲、4 套行星防護裝、1 套迷宮副本裝。每套都是頭盔 / 胸甲 / 護腿 / 戰靴四件，穿戴時被動觸發效果。

另外還有 **1 件單品：太陽能頭盔**（沒有成套的胸甲護腿戰靴），所以護甲類物品合計 **33 件**。

---

## 泰坦套裝（二階）

基礎科技護甲，在**製造機**中合成，主體材料是複合面板。

| 部件 | 效果 | 材料 |
|---|---|---|
| 泰坦頭盔 | 自動獲得防火抗性 | 複合面板 + 電路板 |
| 泰坦胸甲 | 承受傷害降低 10% | 複合面板 + 碳纖網 |
| 泰坦護腿 | 獲得速度 I | 複合面板 + 銅線 |
| 泰坦靴子 | 摔落傷害降低 50% | 複合面板 + 橡膠片 |

## 行星防護套裝（四階）

為五顆星球的極端環境設計的專用套裝，全部在**行星鍛造台**合成。每件都以共同基底加上該星球的專屬防護層：

- **共同基底**：外骨骼框架 + 密封織層
- **部位材料**：頭盔=玻璃板、胸甲=碳纖網、護腿=絕緣導線、戰靴=橡膠片

### 抗輻射套裝 — 奧蕾莉亞

抵抗奧蕾莉亞的星塵與污染地表。專屬防護層＝**輻射網層**。

| 部件 | 說明 |
|---|---|
| 抗輻射頭盔 / 胸甲 / 護腿 / 靴 | 隔絕強輻射與毒性微粒，安全探索污染星球 |

### 抗寒套裝 — 克里昂

抵抗克里昂的極寒與冰霜風暴。專屬防護層＝**低溫內襯**。

| 部件 | 說明 |
|---|---|
| 抗寒頭盔 / 胸甲 / 護腿 / 靴 | 內建保溫層與穩定器，降低低溫對行動的影響 |

### 抗壓套裝 — 倪克斯

抵抗倪克斯的真空與壓差環境。專屬防護層＝**壓差膜層**。

| 部件 | 說明 |
|---|---|
| 抗壓頭盔 / 胸甲 / 護腿 / 靴 | 穩定內外壓差與視野，適應低重力真空地形 |

### 前線套裝 — 全星球通用

抵抗赫利昂與坦佩斯特的**所有**環境危害，可在**五顆星球**自由活動，是最終極的行星防護裝。專屬防護層＝**前線核心 + 耀焰屏護層 + 風暴導流層**。

| 部件 | 說明 |
|---|---|
| 前線探勘頭盔 | 同時對抗輻射、極寒、真空、熱浪與電暴 |
| 前線探勘胸甲 | 內建多層防護模組，是前線套裝主體 |
| 前線探勘護腿 | 維持極端行動穩定性 |
| 前線探勘靴 | 適應低重力、極寒冰面與高熱地表 |

> 💡 前線核心由多顆星球的高階遺跡成果整合而成，是行星裝研究的頂點。

| 部件 | 效果 | 材料 |
|---|---|---|
| 迷宮頭盔 | 內建回聲定位雷達，瘴氣中維持視野，穿戴時獲得夜視 | 守衛者核心 + 迷宮碎片×6 + 迷宮蔓藤×4 + 迷宮遺物 |

| 迷宮靴 | 底部刻有回聲紋路，可偵測附近牆壁結構變化 | 守衛者核心 + 迷宮碎片×5 + 迷宮蔓藤×3 + 迷宮遺物 |

| 部件 | 說明 |
|---|---|
| 防輻射頭盔 / 胸甲 / 護腿 / 靴 | 鉛合金內襯，四件組合時完全阻斷輻射傷害 |
