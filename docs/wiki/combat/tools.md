# 工具

科技工具提供各種功能性能力，從採礦、農務到移動與收納。共 **22 種**，多數在製造機或力場鍛造台合成，少數以進階工作台手工組出。

> 移動類與部分裝置屬於**通電工具**：使用時消耗電量，對準儲能機器 **蹲下 + 右鍵** 即可充電。

## 🔧 機器維護

### 科技扳手

多功能維護工具，**不消耗耐久**。以**進階工作台**（工作台疊在鐵方塊上）合成，材料為鐵錠 + 銅錠 + 鐵板。

| 操作 | 效果 |
|---|---|
| **左鍵** 機器 | 開關機省電 |
| **蹲下 + 右鍵** 機器 | 瞬間拆除並回收機器 |

### 物流扳手

快速設定機器物流方向的專用工具，在**製造機**合成（鐵板 + 銅錠 + 邏輯閘）。

| 操作 | 效果 |
|---|---|
| **左鍵** 機器 | 設定為輸入面 |
| **右鍵** 機器 | 設定為輸出面 |

> 對電流機器使用時，物流扳手改為設定電力的輸入 / 輸出方向。
