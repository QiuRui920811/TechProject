# 戰鬥裝備

TechMC 提供完整的武器、護甲、護符和工具系統，並有一套獨立於原版的**特殊附魔**體系可疊加強化。

---

## 裝備總覽

| 類型 | 數量 | 階級範圍 |
|---|---|---|
| [武器](weapons.md) | 16 種 | 三～四階 |
| [護甲](armor.md) | 8 套（32 件）＋ 太陽能頭盔 | 二～四階 |
| [護符](talismans.md) | 13 種 | 二～三階 |
| [工具](tools.md) | 22 種 | 二～四階 |
| [特殊附魔](enchants.md) | 20 條 | I / II / III |

> 💡 [特殊附魔系統](enchants.md)走物品物品內建資料儲存、不佔原版附魔欄，可疊在武器 / 弓 / 防具 / 工具上，另有專頁詳細說明。

---

## 裝備取得

戰鬥裝備需要在對應的科技機器中合成：

| 機器 | 可製造裝備 |
|---|---|
| 進階工作台 | 淘金盤、科技扳手 |
| 製造機 | 泰坦套裝、多種工具（磁石 / 背包 / 鐮刀 / 水培鏟 / 抓鉤 / 合成台 / 垃圾桶 / 掃描儀 / 物流扳手） |
| 進階製造機 | 脈衝推進器 |
| 力場鍛造台 | 三階武器 ×5、基礎護符 + 6 種二階護符、多種戰鬥 / 採集工具 |
| 雷射雕刻機 | 6 種三階護符 |
| 量子處理器 | 量子套裝 |
| 物質編譯器 | 虛空套裝、四階武器 ×5、秘法傳說武器 ×4 |
| 行星鍛造台 | 4 套行星防護裝、迷宮套裝、迷宮武器、風暴噴射背包 |

---

## 裝備階級

```
二階: 泰坦套裝（基礎護甲）
 ↓
三階: 量子套裝 + 三階施法武器 + 護符
 ↓ ↓
 │ 行星防護套裝 ×4（星球探索必備）
 ↓
四階: 虛空套裝 + 四階科技武器
 + 迷宮套裝 / 迷宮武器（副本專屬）
 + 秘法傳說武器（魔力隕石打造，最強戰力）
```
