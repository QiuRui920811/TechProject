# 能源網路

能源是所有科技機器的動力來源。建立能源網路將發電機的電力傳輸給各台機器。

---

## 發電設備

發電量以 **EU/刻**（每 tick）表示，數字越大功率越高。愈高階的發電機功率愈猛，但也需要愈稀有的燃料。

### 一階發電機

| 發電機 | 燃料 / 來源 | 發電 | 特點 |
|---|---|---|---|
| 太陽能發電機 | 陽光 | 3 EU/刻 | 白天自動發電，夜間停止 |
| 煤炭發電機 | 煤炭 | 2 EU/刻 | 24 小時發電，需持續供料 |
| 岩漿發電機 | 岩漿桶 | 5 EU/刻 | 單桶穩定燃燒 |
| 蒸汽鍋爐 | 煤 / 焦炭 + 水桶 | 8 EU/刻 | 一階最高功率，需同時供水 |

### 二階發電機

| 發電機 | 燃料 / 來源 | 發電 | 特點 |
|---|---|---|---|
| 太陽能陣列 | 陽光 / 星光板 | 3 EU/刻 | 儲能更高（12000 EU）且可加工配方（星光板、網格模組） |
| 生質反應爐 | 作物 | 4 EU/刻 | 用農場副產品發電 |
| 風力渦輪機 | 風 | 3 EU/刻 | 放愈高效率愈佳 |
| 風暴渦輪機 | 天氣 | 晴天 2 / 風暴 8 EU/刻 | 雷暴、大雨時發電量暴增 |

### 三階發電機

| 發電機 | 燃料 / 來源 | 發電 | 特點 |
|---|---|---|---|
| 地熱發電機 | 岩漿桶 | 16 EU/刻 | 岩漿桶穩定發電 |
| 柴油發電機 | 雜酚油 | 24 EU/刻 | 焦爐副產的雜酚油驅動 |
| 燃氣渦輪 | 氫氣 | 50 EU/刻 | 電解水製氫供料，高功率 |
| 核反應堆 | 鈾燃料棒 + 反應堆冷卻液 | 200 EU/秒 | 終局主力電廠，見下方專欄 |

> ⚛️ **核反應堆**：反應堆冷卻液是**永久催化劑**，放入一次後永不消耗；每根鈾燃料棒可運轉 **40 秒**，穩定輸出 **200 EU/秒**（裝加速模組額外 +60 EU）。循環結束會自動輸出乏燃料棒，可送進物質編譯器回收成新燃料棒。**無燃料時完全不發電**。

## 傳輸元件

### 導能線纜

| 屬性 | 值 |
|---|---|
| 階級 | 一階|
| 合成 | 工作台（鐵錠 ×6 + 銅錠 ×1 + 紅石 ×2）／ 組裝機（銅線 + 鐵板） |
| 功能 | 點對點能源傳輸 |

將導能線纜連接在發電機和機器之間，形成傳輸路徑。

### 能源節點

| 屬性 | 值 |
|---|---|
| 階級 | 二階 |
| 合成 | 工作台（銅錠 ×4 + 紅石 ×4 + 避雷針 ×1，`CRC/RLR/CRC`）／ 組裝機（發射節點 + 機械外殼） |
| 功能 | 能源分配中樞 + **5 格輻射供電**（機器不需貼線） |

能源節點是能源網路的核心，除了中繼長距離線路外，**周圍 5 格內的機器會自動吸電**。詳見 [能源基礎 — 節點輻射](../getting-started/energy-basics.md)。

**節點自己也要有電才能輻射。** 它會自動從 5 格內（或線纜連得到）的發電機、電池庫抽電進自己的儲能槽，
所以標準做法是「發電機 or 電池庫 → 放一顆節點 → 節點周圍 5 格擺機器」，中間完全不用牽線。
節點儲能上限 6000 點，打開節點介面就能看到目前存了多少電——**節點是 0 電，周圍機器就吸不到東西**，
這時要檢查的是節點旁邊有沒有電源，而不是機器本身。

## 網路架構

> 💡 發電機直接相鄰機器時可自動供電，不需要導能線纜。導能線纜和能源節點用於跨距離供電。

### 基礎架構

```
太陽能發電機 ──→ 機器       （直接相鄰即可供電）
太陽能發電機 ──[導能線纜]──→ 機器  （跨距離時使用）
```

### 中型架構

```
太陽能發電機 ──┐
煤炭發電機 ──┤
太陽能陣列 ──┘──[導能線纜]──→ 能源節點 ──→ 機器群
                                    │
                                    └──→ 電池庫
```

### 大型架構

```
發電機群 → 能源節點(主) → 能源節點(分支1) → 機器群A
                              → 能源節點(分支2) → 機器群B
                              → 電池庫群
```

## 電池庫

| 屬性 | 值 |
|---|---|
| 階級 | 二階 |
| 合成 | 工作台（銅錠 ×4 + 紅石 ×3 + 紅石燈 ×1 + 鐵錠 ×1，`CRC/RLR/CIC`）／ 組裝機亦有配方 |
| 功能 | 儲存能源，發電過剩時充電，不足時放電 |

### 使用建議

- 搭配太陽能發電機，白天充電、夜間放電
- 星門啟動需要 大量能源，建議提前蓄電
- 多台電池庫可擴大儲電容量
- 電池庫**只從發電機和其他電池庫收電**，不會反過來把加工機器存的電抽走
- 電池庫送電跟發電機同一套規則：直接相鄰、線纜連到、或是**5 格內的能源節點**都會供電
- 儲能上限 6000 點的能源節點配上 24000 點的電池庫，是「夜間／陰天不斷電」最省事的組合
