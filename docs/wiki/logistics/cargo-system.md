# 貨物系統

進階物流管理系統，適用於大規模自動化工廠。

---

## 貨物元件

| 元件 | id | 階級 | 耗能 | 功能 |
|---|---|---|---|---|
| 貨物抽取節點 | `cargo_input_node` | 三階 | 2 EU/刻 | 從相鄰原版容器（箱子/桶/漏斗）抽取物品送入產線 |
| 貨物輸出節點 | `cargo_output_node` | 三階 | 2 EU/刻 | 將輸入物品推送到相鄰原版容器（箱子/桶/漏斗） |
| 漏斗介面 | `hopper_interface` | 二階 | — | 原版漏斗/箱子 ↔ 科技機器的輕量橋接（不需要貨物網路） |
| 貨物管理站 | `cargo_manager` | 三階 | 5 EU/刻 | 無線掃描範圍內同主人的機器並抽取其輸出物品 |
| 貨物驅動器 | `cargo_motor` | 三階 | 1 EU/刻 | 高速物流中繼站，每次傳輸最多 8 件物品 |
| 工業總線 | `industrial_bus` | 三階 | — | 高吞吐量遠距物流骨幹與中繼站 |
| 量子倉儲抽屜 | `cargo_drawer` | 三階 | — | 單一類型大容量倉儲（容量 50,000），可配合貨物網路自動進出 |
| 倉儲匯流站 | `storage_hub` | 二階 | — | 接收任意物流並作為中型緩衝倉 |
| 過濾路由器 | `filter_router` | 三階 | — | 用樣本物品做精準過濾匯流 |
| 分流節點 | `splitter_node` | 三階 | — | 將同一輸出平均拆往多條產線 |
| 垃圾節點 | `trash_node` | 二階 | — | 永久銷毀所有匯入的物品 |

## 網路架構

### 基礎貨物網路

```
原版箱子 ──[貨物抽取節點]──[貨物驅動器]──→ 貨物管理站
                                         ↓
                                    倉儲匯流站
                                         ↓
                              [貨物輸出節點] ──→ 原版箱子
```

### 完整工廠網路

> 💡 貨物系統不是拿來取代所有相鄰傳輸規則。採集機器可直接推送到相鄰機器；但加工機器的產出若要送進另一台加工機器，仍然必須透過物流中繼（導管/節點）或物流終端。貨物抽取節點僅用於從**原版容器**（箱子/桶/漏斗）抽取物品。

```
原版箱子 ──[貨物抽取節點]──[貨物驅動器]──→ 貨物管理站
                                         ↓
                                    倉儲匯流站
                           ┌────┼────┐
                           ↓    ↓    ↓
                      過濾  貨物  垃圾
                      路由器 輸出節點 節點
                        ↓    ↓
                 ┌──────┼──────┐
                 ↓      ↓      ↓
              機器A  機器B  原版箱子
```

## 倉儲匯流站

| 屬性 | 值 |
|---|---|
| 階級 | 二階|
| 功能 | 數位化儲存，容量遠超普通箱子 |
| 特點 |介面查看所有存放物品 |

### 使用要點

- 可連接到貨物管理站自動存取
- 多台倉儲匯流站擴展容量
- 支援搜尋功能快速找到物品

---

## 貨物管理站

| 屬性 | 值 |
|---|---|
| 階級 | 三階|
| 耗能 | 5 EU/刻 |
| 功能 | **無線**掃描範圍內同主人的機器並抽取其輸出物品 |
| 特點 | 不需要一台台接導管，直接遠端匯集產出 |

### 運作方式

- 掃描時只認**同一位主人**的機器，不會動到別人的產線
- 抽到的物品匯入貨物網路，再依規則分流或送入倉儲
- 多餘物品自動送往倉儲匯流站

## 量子倉儲抽屜

| 屬性 | 值 |
|---|---|
| id | `cargo_drawer` |
| 階級 | 三階 |
| 容量 | 50,000（單一物品類型） |
| 功能 | 專存**一種**物品的超大容量抽屜 |

### 使用要點

- 每個抽屜只認第一個放入的物品類型，之後就專門堆放該物品
- 可掛在貨物網路上，由貨物管理站/驅動器自動進出貨
- 適合囤放單一大宗材料（如粗鐵、作物、機械零件）

---

## 速度升級

貨物抽取節點和貨物輸出節點支援**速度模組**升級：

| 升級數量 | 每 tick 搬運上限 |
|---|---|
| 0 個 | 4 個物品 |
| 1 個 | 8 個物品 |
| 2 個 | 12 個物品 |
| 3 個 | 16 個物品 |

- 將**速度模組** (`speed_upgrade`) 放入節點 GUI 的升級欄位（最多 3 個）
- 公式：`4 + 4 × 速度模組數量`
- 適用於輸入節點與輸出節點

## 建設建議

### 小型工廠

```
5-10 台機器 → 1 個貨物管理站 + 1 個倉儲匯流站
```

### 中型工廠

```
10-30 台機器 → 1 個貨物管理站 + 3-5 個倉儲匯流站
              + 過濾路由器分流
```

### 大型工廠

```
30+ 台機器 → 多個貨物管理站分區管理
             + 工業總線連接各區
             + 大量倉儲匯流站
```
