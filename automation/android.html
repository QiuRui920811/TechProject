安卓機器人

AI 工人系統，可自主執行指定任務。

安卓系統概覽

安卓是三階的自動化終極方案。每台安卓機器人可自主執行任務，無需玩家在場。核心是安卓工作站，插入不同的「程序腳本」就會執行不同的工作。

安卓相關設施

設施id階級耗能功能
安卓艙android_bay三階20 EU/秒製造安卓零件
安卓工作站android_station三階12 EU/秒部署與巡檢安卓
安卓物品介面android_item_interface三階4 EU/秒安卓存取箱子中的物品
安卓燃料介面android_fuel_interface三階4 EU/秒安卓燃料自動供應

安卓建造流程

步驟一：製造核心

在進階製造機中合成：

零件材料
安卓核心控制單元 ×2 + 伺服馬達

步驟二：製造零件

在安卓艙中合成：

零件材料
安卓外殼處理塑膠 ×2 + 機械外殼
安卓框架安卓外殼 ×2 + 合成纖維
安卓記憶矩陣安卓核心 ×2 + 數據矩陣

步驟三：建造工作站

在進階製造機中合成：

設施材料
安卓工作站安卓框架 ×2 + 安卓記憶矩陣

步驟四：部署

  1. 放置安卓工作站
  2. 安裝程序腳本（決定任務類型）
  3. 安卓開始自動工作

安卓程序腳本

程序腳本決定安卓的工作內容，分別在製造機或量子處理器中合成：

腳本功能材料機器
農務程序自動種植/收穫作物農業模組 + 邏輯閘製造機
伐木程序自動砍伐附近樹木收割單元 + 伺服馬達製造機
回收程序自動回收指定物品訊號中繼器 + 發射節點製造機
行星採樣程序在行星自動採集資源量子框架 ×2 + 力場發射器量子處理器
探索程序在任何世界探索稀有資源量子框架 ×2 + 安卓記憶矩陣 ×2量子處理器
自訂程序由玩家自行編寫自訂程序腳本安卓記憶矩陣 ×2 + 邏輯閘 ×4量子處理器
獵捕程序獵捕附近生物並收集掉落物內建行為（無獨立腳本物品）—

💡 自訂程序可用 /tech android program 編寫指令腳本，讓工作站執行你自己設計的巡邏邏輯。

💡 探索程序是安卓的獨有能力，沒有其他機器能替代。它可以在任何世界（包括地獄、末地）自動探勘稀有礦物，掉落物隨世界與深度不同：

  • 主世界深層（Y<16）：鑽石、綠寶石原礦、粗金、青金石、粗銅
  • 主世界淺層：鑽石、綠寶石原礦、紫水晶碎片、粗鐵、粗銅
  • 地獄：古代碎片、石英、金粒、螢石粉、岩漿膏
  • 末地：末影珍珠、歌萊果、潛影殼、終界石

安卓升級卡

提升安卓性能的升級，插入工作站的升級欄位即生效：

升級卡效果材料機器
安卓超頻卡程序執行更頻繁，但 EU 與燃料消耗上升速度升級 ×2 + 安卓記憶矩陣進階製造機
安卓節能卡降低能源與燃料成本效率升級 ×2 + 安卓記憶矩陣進階製造機
安卓擴域卡增加巡邏半徑與掃描高度範圍升級 ×2 + 安卓記憶矩陣量子處理器

超頻卡適合供電穩定的大型基地；節能卡適合長時間常駐的前哨巡邏線；擴域卡對伐木、行星採樣與大型農場特別有感。

安全設定

安卓尊重領地保護系統，不會在受保護區域內執行破壞性操作。

建設建議

  1. 起步：先建一台安卓工作站 + 農務程序，實現農業全自動
  2. 擴展：增加伐木程序安卓，自動收集木材
  3. 探索：安卓探索程序，在地獄探勘古代碎片、在深層挖掘綠寶石原礦（鈾自動化的關鍵）
  4. 星球：使用行星採樣程序在星球自動收集稀有資源
  5. 優化：安裝超頻卡和節能卡提升效率

🔧 機器人不動？照這個順序查

安卓工作站右鍵打開，看最上面的狀態列，它會直接告訴你原因：

狀態列意思怎麼處理
燃料不足燃料歸零貼著工作站放一台安卓燃料介面，丟煤炭 / 木炭 / 煤粉 / 烈焰粉 / 精煉油 / 能源電池 / 鋰電池 / 電漿電池 / 熔岩桶進去，會自動補到工作站
電力不足沒接電主世界：旁邊放發電機或電池庫。星球上放不了發電機：回主世界把工作站充飽（容量 7200 EU），用科技扳手拆下（會保留電量）再帶上去
待命：附近沒有可執行目標中間槽沒放程序卡，也猜不出要做什麼把程序卡放進中間那格升級槽（一次只認一張）
巡邏中：…（半徑 N 格內沒找到目標）程序有在跑，但範圍裡沒東西預設半徑只有 2 格、高度 1 格——樹 / 作物要種在工作站旁邊，或裝安卓擴域卡
不是可採樣星球行星採樣程序只在星球世界有效帶安卓工作站 + 燃料介面 + 物品介面上星球放（星球上准放這三台）。工作站要放在資源節點 2 格內，它只採節點，不採普通地表

三張卡的位置：程序卡放中間，超頻 / 節能 / 擴域卡放左右兩格。

燃料容量 256，每次執行扣 1～2（超頻卡 +1、節能卡 −1）。
