工業擴展材料

工業擴展帶來的冶金、機械、電子、鑄造、核電與物流信號材料，共 103 種，是把手動科技線推向大規模工廠的骨幹。

合金進階路線

銅 + 錫 → 青銅（基礎）
鐵 + 焦炭 → 鋼（基礎）
鋼 + 鐵粉 + 碳粉 → 大馬士革鋼（進階）
大馬士革鋼 + 碳化鎢 → 硬化合金（三階）
硬化合金 + 合成鑽石 + 濃縮鈾 → 強化合金（四階 · 終局骨架）

核燃料循環

鈾礦 → [粉碎機] → 鈾礦粉 → [離心機 ×4] → 濃縮鈾
 → [組裝機] 濃縮鈾 ×4 + 鉛 + 鋼棒 → 鈾燃料棒
 → [核反應堆] → 廢鈾棒
 ├→ [離心機] → 鈽 → 鈽燃料棒（更高效）
 └→ [電動化學反應器] 廢鈾棒 ×2 + 反應堆冷卻液 → 濃縮鈾（再處理）

💡 鈽 vs 鈾：鈽燃料棒效率更高，但鈽只能從廢鈾棒離心取得，所以先燒鈾、再煉鈽是固定流程。
