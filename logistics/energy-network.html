能源網路

能源是所有科技機器的動力來源。建立能源網路將發電機的電力傳輸給各台機器。

發電設備

發電量以 EU/秒（每秒）表示，數字越大功率越高。愈高階的發電機功率愈猛，但也需要愈稀有的燃料。

一階發電機

發電機燃料 / 來源發電特點
太陽能發電機陽光3 EU/秒白天自動發電，夜間停止
煤炭發電機煤炭2 EU/秒24 小時發電，需持續供料
岩漿發電機岩漿桶5 EU/秒單桶穩定燃燒
蒸汽鍋爐煤 / 焦炭 + 水桶8 EU/秒一階最高功率，需同時供水

二階發電機

發電機燃料 / 來源發電特點
太陽能陣列陽光 / 星光板3 EU/秒儲能更高（12000 EU）且可加工配方（星光板、網格模組）
生質反應爐作物4 EU/秒用農場副產品發電
風力渦輪機風3 EU/秒放愈高效率愈佳
風暴渦輪機天氣晴天 2 / 風暴 8 EU/秒雷暴、大雨時發電量暴增

三階發電機

發電機燃料 / 來源發電特點
地熱發電機岩漿桶16 EU/秒岩漿桶穩定發電
柴油發電機雜酚油24 EU/秒焦爐副產的雜酚油驅動
燃氣渦輪氫氣50 EU/秒電解水製氫供料，高功率
核反應堆鈾燃料棒 + 反應堆冷卻液200 EU/秒終局主力電廠，見下方專欄

⚛️ 核反應堆：反應堆冷卻液是永久催化劑，放入一次後永不消耗；每根鈾燃料棒可運轉 40 秒，穩定輸出 200 EU/秒（裝加速模組額外 +60 EU）。循環結束會自動輸出乏燃料棒，可送進物質編譯器回收成新燃料棒。無燃料時完全不發電。

傳輸元件

導能線纜

屬性值
階級一階
合成工作台（鐵錠 ×6 + 銅錠 ×1 + 紅石 ×2）／ 組裝機（銅線 + 鐵板）
功能點對點能源傳輸

將導能線纜連接在發電機和機器之間，形成傳輸路徑。

能源節點

屬性值
階級二階
合成工作台（銅錠 ×4 + 紅石 ×4 + 避雷針 ×1，CRC/RLR/CRC）／ 組裝機（發射節點 + 機械外殼）
功能能源分配中樞 + 5 格輻射供電（機器不需貼線）

能源節點是能源網路的核心，除了中繼長距離線路外，周圍 5 格內的機器會自動吸電。詳見 能源基礎 — 節點輻射。

節點自己也要有電才能輻射。 它會自動從 5 格內（或線纜連得到）的發電機、電池庫抽電進自己的儲能槽， 所以標準做法是「發電機 or 電池庫 → 放一顆節點 → 節點周圍 5 格擺機器」，中間完全不用牽線。 節點儲能上限 6000 點，打開節點介面就能看到目前存了多少電——節點是 0 電，周圍機器就吸不到東西， 這時要檢查的是節點旁邊有沒有電源，而不是機器本身。

網路架構

💡 發電機直接相鄰機器時可自動供電，不需要導能線纜。導能線纜和能源節點用於跨距離供電。

基礎架構

太陽能發電機 ──→ 機器 （直接相鄰即可供電）
太陽能發電機 ──[導能線纜]──→ 機器 （跨距離時使用）

中型架構

太陽能發電機 ──┐
煤炭發電機 ──┤
太陽能陣列 ──┘──[導能線纜]──→ 能源節點 ──→ 機器群
 │
 └──→ 電池庫

大型架構

發電機群 → 能源節點(主) → 能源節點(分支1) → 機器群A
 → 能源節點(分支2) → 機器群B
 → 電池庫群

電池庫

屬性值
階級二階
合成工作台（銅錠 ×4 + 紅石 ×3 + 紅石燈 ×1 + 鐵錠 ×1，CRC/RLR/CIC）／ 組裝機亦有配方
功能儲存能源，發電過剩時充電，不足時放電；本身也是一台加工機

使用建議

  • 搭配太陽能發電機，白天充電、夜間放電
  • 星門啟動需要大量能源，建議提前蓄電
  • 多台電池庫可擴大儲電容量
  • 儲能上限 6000 點的能源節點配上 24000 點的電池庫，是「夜間／陰天不斷電」最省事的組合

電怎麼進、怎麼出

  • 只從發電機收電。 不會去搶別的電池庫或能源節點的電 —— 兩邊互相抽會卡在原地誰也動不了。
  • 往直接相鄰、線纜連得到的機器放電。
  • 要餵能源節點的話，是節點自己過來抽，不用你牽線。所以「電池庫 → 旁邊擺一顆節點 → 節點周圍 5 格擺機器」照樣成立。
  • 反過來說：電池庫不會像發電機那樣主動輻射給 5 格內的節點，得靠節點來拿。

它也會做東西

電池庫不只是個電桶，它有自己的配方：能源電池 + 鋰電池 + 錫板 → 電容組（還有鋰電池、發射節點）。

做東西要吃 2 EU/秒，而它的電只能從發電機來 —— 所以只接了能源節點卻沒接發電機的話，它存不到電，配方也做不出來，材料會一直卡在輸入格。

產物會照物流網路的規則自動送出去（物流節點、工業總線、漏斗介面都拉得到）。
