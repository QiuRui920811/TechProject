物品傳輸

使用物流導管和物流節點建立自動物品搬運網路。

傳輸元件

物流導管

屬性值
階級一階
合成工作台 (壓力導管 ×3)
功能物品傳輸通道

將物流導管連接在機器之間，形成物品傳輸路徑。

物流節點

屬性值
階級二階
合成工作台 (鐵錠 ×4 + 訊號中繼器)
功能物品分配中樞

物流節點是物品傳輸網路的核心，可以連接多條物流管路。

網路配置

💡 採集機器可以直接把物品推送到相鄰機器；但如果是加工機器 → 加工機器，仍然必須透過物流導管、物流節點或物流終端（如倉儲匯流站、過濾路由器）做中繼，直接貼鄰不會自動傳輸。

點對點傳輸

洗礦機 ──[物流導管]──→ 電爐

將一台機器的輸出透過導管送到另一台。若來源與目標都是加工機器，這也是必要條件，不是可選優化。

中樞傳輸

粉碎機 ──┐
電鋸 ──┤──→ 物流節點 ──→ 電爐
自動農場──┘ ──→ 壓縮機
 ──→ 製造機

使用物流節點作為中心，連接多台機器。

分流元件

分流節點

屬性階級功能
分流節點三階將物品平均分配到多條路徑

過濾路由器

屬性階級功能
過濾路由器三階根據物品類型過濾分配

使用方式

  • 前 1~3 格放入「樣本物品」定義過濾規則（最多 3 種）
  • 後面的 input 格（slot 4~9）才是流入要被過濾的物品
  • 介面切換 白名單（只放樣本）／黑名單（放樣本以外的）

⚠️ 常見錯誤擺法

陷阱 A：樣本中間空格

樣本必須從第 1 格連續放，遇到空格就停止讀取後面的格子。

❌ 錯誤：[鐵粉] [空] [銅粉]
 ↑ ↑ ↑
 樣本停！ 被當成要過濾的物品 → 反而被路由出去

✅ 正確：[鐵粉] [銅粉] [鉛粉]
 三種都被當作樣本

陷阱 B：樣本來源不對

樣本必須是機器產出的科技物品，不能用 /give 拿原版染料替代：

物品看起來電腦識別
機器產的銅粉橘色染料外觀copper_dust（科技 ID）
原版橘色染料一模一樣orange_dye（原版 ID）
機器產的鉛粉灰色染料外觀lead_dust（科技 ID）
原版灰色染料一模一樣gray_dye（原版 ID）

兩個 ID 不匹配 → 過濾器找不到對應物品 → 銅粉/鉛粉過不出來。

最簡單的解法：把實際要過濾的那個物品複製一份放樣本格，100% 對得上。

銷毀節點

屬性階級功能
銷毀節點二階銷毀不需要的物品

進階分流元件

優先路由器

屬性階級功能
優先路由器三階依過濾欄設定優先物品，匹配項走主路、其餘走備路

使用方式與過濾路由器相似，前 1~3 格放入樣本物品定義「優先物品」。

合成：優先級模組 + 分流核心 + 訊號中繼器×2 → 製造機

輪流分配器

屬性階級功能
輪流分配器三階平均分配物品到多台下游機器（Round-Robin）

與分流節點類似，但嚴格輪流——確保每台下游機器收到相同數量的物品。

合成：分配齒輪 + 分流核心 + 訊號中繼器×2 → 製造機

溢出處理器

屬性階級功能
溢出處理器二階主路滿載時自動轉送備用路線

優先向主路（輸出方向）推送物品；當主路下游全滿時，自動切換到備用路線。適合搭配銷毀節點或倉儲匯流站做防堵塞。

合成：溢出閥 + 分流核心 → 製造機

漏斗介面

屬性階級功能
漏斗介面二階原版漏斗/箱子 ↔ 科技機器的物品橋接

原版箱子跟科技機器之間的轉接頭。每 5 秒做一輪，一輪同時做三件事：

  • 自己收到的貨 → 相鄰箱子（物流網路推進來的東西從這裡出去）
  • 旁邊科技機器的產出 → 相鄰箱子
  • 相鄰箱子的東西 → 旁邊科技機器的輸入格

一輪搬 16 個，每片速度模組再 +16（插滿 3 片就是 64 個）。

出料往哪邊走：介面裡設的輸出方向說了算。留在「全方向」時，優先走方塊面朝的那一面，再來是下方，最後才是其餘四面。剛送出貨的箱子，同一輪不會再從它身上抽東西回來，所以材料跟成品不會混在一起。

旁邊沒有科技機器也沒關係 —— 自己身上的貨照樣會送進箱子。

合成：漏斗轉接模組 + 機械零件 → 製造機

網路距離（最長連結距離）

物流網路靠 ** 深度** 限制傳輸範圍，沒有「絕對格數」概念，深度算法如下：

元件深度加成（物流模式）
基礎深度8 格
範圍升級（每片）+6 格
工業總線 industrial_bus+16 格（在自身為起點時）
貨物管理站 cargo_manager+32 格
倉儲匯流站 storage_hub+8 格
貨物驅動器 cargo_motor+8 格

各機器的最長連結距離

「連結距離」= 從該機器出發， 能掃到的最遠 node 數。中繼節點（如另一根工業總線）會重置深度計數，等於信號放大器。

起點機器0 升級1 範圍升級2 範圍升級3 範圍升級
物流導管 / 物流節點（一般）8142026
倉儲匯流站 / 貨物驅動器16222834
工業總線24303642
貨物管理站40465258

工業總線的設計用途：高吞吐量遠距物流骨幹。每段 24 格，串接 N 條工業總線就能拉 24×N 格網路（每條都會重置深度）。

💡 能量網（能源節點 / 導能線纜）使用同樣的深度公式但沒有工業總線加成，純走 8 + 6×範圍升級。

應用範例

自動碎礦冶煉線

粉碎機 ──[物流導管]──→ 過濾路由器
 ├──→ 電爐 (粉末→錠)
 ├──→ 壓縮機 (鐵錠→鐵板)
 └──→ 銷毀節點 (多餘材料)

農業生產線

自動農場 ──→ 物流節點 ──→ 生質實驗室 (作物→食物)
 ──→ 洗礦機 (作物→粉碎生質)
 ──→ 倉儲匯流站 (存放多餘)
